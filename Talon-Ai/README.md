# TALON Studio

Agentic AI + RAG talent intelligence platform with human approval gates.
Free, open source, runs on your laptop. Python standard library only (pypdf optional, for PDF resumes).

    python run.py          (Windows: py run.py)

Then open http://localhost:8000 and click **Load demo portfolio**.

- `python run_tests.py` runs the self-test.
- AI engine (optional): Settings page - Ollama, GitHub Models, or any OpenAI-compatible API.
- Put your own policy documents (.txt / .md) in the `knowledge` folder.
- Agent details: docs/AGENT_SPECS.md
